# 两臂读数都为空时先当探针故障：先测现象首现时机，再开对比臂

**主张**：差分/对照探针（A/B 两臂）若两臂逐帧读数完全相同、且都是空集（本例 20 帧航迹全是 `()`），**不要把它当「两臂无差异」的结论**——先按探针无效处理：回到单臂基线，**逐帧**打印被测量，量出被测现象**第一次出现的时机**（第几帧 / 多少预热），确认这个读出口径真能看到现象，再把对比窗口挪到现象出现之后，重开双臂对比。

**为什么**：时序/竞态类缺陷的信号只在特定时刻（或特定调用路径）出现。观察窗口落在现象发生之前、或探针读的是另一条不产出该现象的路径时，两臂都会给出同样的空读。空结果读起来像一条干净的「无差异」结论，实则是最容易掩盖缺陷的假阴性（把「探针没看到」读成「系统没有」）。

**证据（切片命令 ↔ 结果）**：
- `python3 /tmp/race_probe2.py` → `clean tracks : [(), (), (), (), (), (), (), (), (), (), (), (), (), (), (), (), (), (), (), ()] ctrl  tracks : [(), (), ...]`——20 帧内两臂航迹**全空**；只看这行就是「clean 与 ctrl 无差别」。
- 改写出的 `/tmp/dbg.py` 逐帧打印三元组读数 → `trial 0 [(22, 0, []), (22, 0, []), (22, 0, []), (22, 0, []), (22, 0, []), (22, 0, []), (22, 1, [1]), (22, 1, [1]), (22, ...`——三元组第二项前 6 帧恒为 0、第 6 帧起变成 1，与 `race_probe3` 自报的「track 首现于第 6 帧」吻合；说明原先的空读来自观察窗口/读出口径，而不是两臂真的没差别。
- `python3 /tmp/race_probe3.py` → `基线: track 首现于第 6 帧, 之后恒为 ((1, -0.106),)  --- trial 0 --- A 建 B 前 track: ((1, -0.0708),) (已跑 10 帧) A 在 B 构造后 0.3s 内的 track…`——改为**先打单臂基线（首现帧 + 稳定读数）再跑试验臂**，比较才落在有信号的窗口里。

**边界 / 反例**：
- 空结果本身不是无效判据：若基线确认现象在该路径上不会发生（且已确认读出口径能看到该现象），「两臂都空」才是有效结论。判「探针无效」的依据是**基线跑不出已知会出现的现象**，或两臂与基线的差恒为零。
- 稀有事件（只在特定调度下出现）可能连基线也跑空，此时应重复基线 / 加日志，而不是直接判探针坏——本条只主张「先建立基线再解释空结果」，不主张「空结果一律是探针错」。
- 读数若是离散量（id 列表 / 命中集合），「两臂相同」要连首现帧序号一起比，不能只看集合是否相等。

**失败信号（未来命中即该想起本条）**：
- 对照实验里两臂打印的逐帧数组一模一样，且都是空 / 零，正准备写「未观察到差异」。
- 探针跑完全程没有任何一帧读到被测对象（航迹数 / 命中数 / 事件数恒 0），却要下「缺陷不存在」。
- 说不出被测现象在第几帧（或多少预热后）出现。
