# Evo Capture — 零成本捕获

## 用法
```bash
evo capture "<要记的一句话>"
```

## 原则
- **捕获与整理解耦**：现在只记，归类/验证/蒸馏留给收工（evo-learn）或复盘（evo-reflect）。
- 一句话即可，别打断心流。来源会话会自动关联（session-end 登记）。
- 捕获内容进 `<EVO_ROOT>/inbox/`，后续由蒸馏流程处理。
