macOS 自带 `/bin/bash` 是 3.2（2007 年发布），没有 `mapfile`/`readarray` 内建命令（bash 4.0+ 才有）；在 macOS 上写 shell 脚本，把文件读进数组要用 while-read 循环，或直接换 zsh/Python。

为什么：跑 `scripts/survey-engines.sh` 报 `line 38: mapfile: command not found`；改为 bash 3.2 兼容的 while-read 写法后 `bash -n` 语法检查通过、脚本正常运行。

反例/边界：`bash -n` 只做语法检查，不校验内建命令是否存在于当前 bash 版本，所以「语法 OK」不等于「能在 macOS 3.2 上跑」，版本差异的内建命令缺失要靠实跑暴露。
