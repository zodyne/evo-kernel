# 钳位饱和的实测签名：误差随过驱线性增长且符号翻转=0（回绕会翻转）

## 主张

判定定点量化器的饱和实现是**钳位**还是**回绕**，用同一浮点输入跑一次、统计**逐分量误差**与**符号翻转数**：钳位实现过驱时码值顶在两端边界（实测 `[32767, −32768]`），最大逐分量误差随过驱幅度增长（单音 1.2×FS，只超 20% → `max|eI| = 6143.5 LSB = 18.75% FS`、`RMS(err) = 4097.2 LSB`），且**符号翻转 = 0**（误差全程同号）；回绕实现的对照预期是在折回点把误差符号翻转。只按"码值是否越界"判断，两种模式分不开。

## 为什么

钳位把误差累积在同一方向上（一直偏大/偏小），回绕在折回点把误差符号反过来。两者的输出码值都落在合法 int16 范围内（回绕尤其看不出来，见 related），所以必须统计**误差**而不是看**码值**——而误差符号翻转数正是两者最直接的判别量。

## 做法

构造已知浮点输入（如单音 1.2×FS，只超 20% 就够），量化后逐分量打印三项：`max|eI|`、`RMS(err)`、过驱样本的误差符号翻转计数。轻度过驱即可分辨，不必打到满量程。

## 反例 / 边界

- 过驱幅度不足 1 LSB 时误差淹没在量化噪声里，分不出饱和模式。
- **误差上界两端不对称**：负轨是 −2^15（−32768）、正轨是 2^15−1（32767）——实测钳位码值 `[32767, −32768]`；写 `max|e| = A − (2^15−1)` 这类对称断言会漏掉负半轴的 1 LSB。
- 本条切片只实测了 saturate=True（钳位侧）的签名；回绕侧的折回/翻转是待对照的预期，不是本次实测值。

## 证据（切片命令 ↔ 结果）

- 检查设计（切片原样）：`B2 饱和：钳位 vs 回绕（同一帧、同一浮点输入，逐分量统计）`。
- 钳位侧签名：`B2b 轻度过驱：单音幅度 1.2×FS（只超 20%）  A=1.2FS saturate=True : max|eI|= 6143.5 LSB = 18.75% FS  RMS(err)= 4097.2 LSB  符号翻转=0/8`。
- 最小复现：`钳位码值: [ 32767.+0.j −32768.+0.j]  2^15-1 = 32767 saturate=True  max|eI|= 6143.5 LSB (18.75% FS)  符号翻转=0/4096`。
- 旁证：`lsb 3.051850947599719e-05  peak_code 32767  max|one| 1.2  …  clipped 1`。

## 失败信号（未来命中即该想起本条）

- 饱和断言只检查了码值边界，没有误差/翻转统计。
- 负半轴过驱样本的最大误差与正半轴用同一公式算。
