hermes cron create 的位置参数（schedule/prompt）必须写在所有选项之前：Created job: a17ab35b35a1
  Name: X
  Schedule: 0 9 * * 1
  Next run: 2026-08-17T09:00:00+08:00
  ⚠  Gateway is not running — jobs won't fire automatically.
     Start it with: hermes gateway install
                    sudo hermes gateway install --system  # Linux servers
     Check status:  hermes cron status 才行；把 prompt 放选项后面会被顶层 parser 报 unrecognized arguments（usage 打的是主 parser 不是子命令，具迷惑性）。
