Claude Code 本地插件部署：claude plugin marketplace add <本地目录> 可行（要求仓库含 .claude-plugin/marketplace.json 且 plugin source 为 ./）；安装名为 <plugin>@<marketplace.json的name字段>，与 quickstart 写的 GitHub 市场名可能不同（harness 案例：本地是 harness@harness-marketplace 而非 harness@harness）。CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS 等实验 flag 持久化到 ~/.claude/settings.json 的 env 块比写 shell rc 更可靠（覆盖所有 claude 会话）。macOS 无 timeout 命令（需 gtimeout 或用工具自带超时）。
