nvim :terminal 里 CLI agent 到顶滚不动 = 它进了备用屏(CSI ?1049h)：libvterm 只把主屏滚出顶部的行推进 scrollback，备用屏一行不留，buffer 行数恒==winheight（同一 nvim 打 200 行：主屏 201 行 / 备用屏 28 行）。pi 是 ~/.pi/agent/settings.json tuiMode=fullscreen（起时传 --tui-mode regular 覆盖）；Claude Code 2.1.x 默认进备用屏（env CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1 关）。用 python pty.fork 抓原始输出数 \x1b[?1049h 可证；script(1) 起 claude 拿不到字节、且在未信任目录只会先出 trust 对话框不进备用屏。sidekick 自带 scrollback 模块只在 mux(tmux/zellij) 能 dump pane 时生效。
